About MT

        

          MT is a small procedural language with typed variables, functions,
          conditionals, loops, and interactive integer I/O. Programs are
          compiled to TAM (Triangle Abstract Machine) instructions and run on a
          stack-based virtual machine.
        

        

          This playground uses the original Haskell compiler from the cw2
          university coursework, running on a Cloud Run backend.
